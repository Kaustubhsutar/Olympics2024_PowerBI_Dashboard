## 🗂 Dataset Overview

The dataset was sourced from **Kaggle** using Python-based automated dataset downloading and management workflows.

### Kaggle Dataset Used

- **Dataset:** `piterfm/paris-2024-olympic-summer-games`
- **Source:** Paris 2024 Olympic Summer Games Dataset

The project uses Python scripts with the Kaggle API to:

- Automatically download Olympic datasets
- Remove outdated files
- Manage dataset updates
- Load CSV datasets into Pandas DataFrames
- Prepare data for Power BI transformation workflows

The project uses the following analytical tables:

| Table Name | Purpose |
|---|---|
| `Athletes` | Athlete demographic and participation data |
| `Countries with Flags URL` | Country mapping with flag image URLs |
| `Historical` | Historical Olympic medal records |
| `Icons` | Sports/event icon mapping table |
| `Medalist` | Athlete-level medal winner information |
| `Medals` | Medal distribution dataset |
| `Teams` | Team participation information |
| `Total Medals` | Aggregated medal statistics by country |

Additional supporting datasets and lookup tables were engineered to improve dashboard storytelling, filtering, and visual experience.

### 🥇 United States Emerged as the Top Olympic Nation

The United States dominated Olympic 2024 with the highest medal tally and strong gold medal performance.

Gender analysis revealed:

## 🧮 Advanced DAX Measures


## 1️⃣ Gender-Based Gold Medal Analysis

```DAX
GoldByFemaleAthletes =
CALCULATE(
    [Total Gold Medals Country],
    Medals[gender]="W"
)

GoldByMaleAthletes =
CALCULATE(
    [Total Gold Medals Country],
    Medals[gender]="M"
)
```

### 📌 Business Insight

> Enables comparative medal intelligence between male and female athletes across countries and disciplines.


## 2️⃣ Dynamic Olympic Highlights KPI

```DAX
Highlights =
"🏅 Olympic 2024 Highlights" & UNICHAR(10)&

"• Total athletes: " & [Total Athletes] &
" (Male: " & [Total Male Athletes] &
", Female: " & [Total Female Athletes] & ")" & UNICHAR(10) &

"• Gold Medals - Men: " & [GoldByMaleAthletes] &
", Women: " & [GoldByFemaleAthletes] & UNICHAR(10) &

"• Top Performing Country: " & [HighestPerformanceCountry]
```

### 📌 Business Insight

> Generates storytelling-based KPI narratives dynamically inside the dashboard.


## 3️⃣ Athlete Age Categorization

```DAX
Age Category =
SWITCH(
    TRUE(),
    'Athletes'[Age] >= 15 && 'Athletes'[Age] <= 20, "15-20",
    'Athletes'[Age] > 20 && 'Athletes'[Age] <= 25, "21-25",
    'Athletes'[Age] > 25 && 'Athletes'[Age] <= 30, "26-30",
    'Athletes'[Age] > 30 && 'Athletes'[Age] <= 35, "31-35",
    'Athletes'[Age] > 35 && 'Athletes'[Age] <= 40, "36-40",
    'Athletes'[Age] > 40 && 'Athletes'[Age] <= 45, "41-45",
    'Athletes'[Age] > 45 && 'Athletes'[Age] <= 50, "46-50",
    'Athletes'[Age] > 50, "51+",
    "Under 15"
)
```

### 📌 Business Insight

> Segments athletes into analytical age bands for demographic intelligence and participation analysis.
